**Como usar:** cada linha traz o ID do arquivo no Drive. Com o conector do Google Drive disponível, leia o arquivo com `read_file_content(fileId)`, ou faça uma busca com `search_files` usando `parentId = '<ID da pasta>' and fullText contains '<termo>'`. O link para o usuário abrir é `https://drive.google.com/file/d/<ID>/view`. Livros grandes (acima de ~20 MB) podem vir truncados ou demorar. Nesse caso, prefira o PDF menor do mesmo item, quando houver, ou só indique o arquivo e o capítulo.
